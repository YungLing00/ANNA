# ANNA · 雷諾曼牌室

繁體中文、可直接部署的靜態雷諾曼卡網站。深紫與香檳金牌桌、36 張原創 SVG 線稿牌面，不需後端或 API 金鑰。

## 功能

- 標準 36 張牌、固定編號與撲克牌對應，無逆位。
- 雙牌、三牌、九宮格、Grand Tableau（9×4）。
- 安全隨機數洗牌、不重複抽牌、手動選牌或自動抽完。
- 有順序的組合提示；九宮格中心、橫列、直列與斜線；大牌陣宮位及指示牌周邊。
- 牌義搜尋、牌面詳情、主題建議。
- 本機紀錄、觀察筆記、重新載入、刪除、文字複製與下載。
- 手機適配、鍵盤操作、減少動畫設定。

## 使用

直接開啟 index.html，或在本資料夾執行 `python3 -m http.server 8000`。GitHub Pages 可使用 main 分支的根目錄。網站無建置依賴，Google Fonts 載入失敗會回退至系統字型。

## 解讀與隱私

解讀為內建規則，不是 AI 或預測模型，不會解析使用者的問題。主題選項調整實際觀察建議。紀錄保存在 localStorage，沒有上傳功能；清除瀏覽器資料會失去紀錄。無外部追蹤或後端。

Grand Tableau 提供入門宮位與周邊解讀，不是完整的專業大牌陣判讀。文字為原創組合提示，各流派牌義可能不同。內容供娛樂與自我整理參考。

牌組編號與撲克牌對應核對來源：https://www.runastra.com/en/grimoire/lenormand/methodes/petit-lenormand-36-cartes
